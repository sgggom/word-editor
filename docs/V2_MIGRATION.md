# 游戏词库配置迁移记录

2026-10-20，更新至版本 2026.10.20.2：关卡台使用七游戏词库与独立词池配置，预建八份四游戏分级词库，生成时分别多选必答和仅额外词库。此前 Word Tiles v2 引擎接入说明和旧词库审核原稿归档在 `archive/legacy-vocabulary-2026-10-19/`。

## 数据与默认值

迁移已校准分享页的 7 款游戏、25 份配置或资源版本、32,268 个词条，完整保留四类来源身份和逐关引用。全部集合运算数据内嵌，出处 gzip 分包按需加载。预建词库使用 Word Tiles、Zen Word、Words of Wonders、Wordscapes 全部版本，按恰好 4、3、2、1 款分为核心、一级、二级、三级，必答与仅额外分别保存，共 8 份。生效必答分别为 1,627、1,736、2,643、4,742，生效仅额外分别为 177、1,509、4,591、5,415。默认与 CLI 校验词表为核心必答。

仅额外合并三类额外来源，通过词池 `excludeTargets: true` 剔除所选游戏全部版本的有效必答候选。此规则在集合分区之前执行，浏览器、Node、饼图和快照一致。八份默认配置两池同时保存 `excludeTwoLetter: true`，在分区前排除两字母词，生效仅额外合计 11,692 个。四档使用互斥区域，全部生效词不重叠。

旧词库的生成权限、词形隔离、基础标签和审核分数退出运行。生成引擎保留棋盘结构和路径安全目标，使用统一编译后的新词表。旧快照和未设置排除规则的其他自定义配置仍按自己的词表处理；八个预设的新快照不再包含两字母词。

## 文件与存档兼容

词库配置存入既有 IndexedDB `kv` 的 `libraries` 键。当前关序和历史文件结构继续沿用，编辑器文件添加 `librarySnapshots`，每关添加 `librarySnapshotId`。快照固定配方、版本、数据指纹、生效词表和禁表，修改或删除配方不会重写已有关卡。缺少快照的历史关卡绑定核心必答配置，保留内容；有引用但缺少快照或内容校验失败的文件阻止导入。

游戏导出九字段与 `{books, daily}` 格式继续使用，不携带编辑器词库信息；如需继续编辑并保持自定义词库，应保存关卡台文件。WT／Zen 竞品关表继续提供查阅。2026.10.20.1 起，8 个默认词库的三字母及以上词条共用一份内嵌双语释义与音标（22,452 个去重词），原释义分片只为范围外词条回退使用；释义更新不改变词库权限或既有关卡快照。

批量组合快照继续使用 `schemaVersion: 1`，其中 `recipe.kind: library-selection`，`recipe.selection.target / extra` 记录完整来源配方及版本，`lex` 固定合并后的生效词表。旧单配方快照继续可用，组合快照只随关卡台文件保存。生成选择保存在 IndexedDB `kv/batchLibraries`，不改变八词库预设版本标记，升级后保留已有配置。

## 构建约定

`tools/sync_editor.py` 调用共享 JavaScript 集合编译器生成默认词表，再同步脚本、数据与两个 HTML。旧审核程序不进入当前构建或测试发现路径。新增回归覆盖集合语义、快照、来源和生成，原路径、试玩、导入导出回归继续运行。具体命令见根目录 README。

八词库初次迁移使用 `four-game-tiers-v1`，按用户当时要求替换之前的旧配方。2026.10.20.2 使用 `four-game-tiers-v2`：从 v1 升级时只对当前仍存在的八个预设 ID 设置两池 `excludeTwoLetter: true`，发生变化才增加 revision。保留用户编辑、默认配置、多选偏好、其他自定义配置及所有旧关卡快照；删除的预设不恢复，刷新不会反复升级。
