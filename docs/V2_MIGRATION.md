# v2 接入记录

当前编辑器接入用户提供交接包中的 `WordTiles_关卡工作台_v2`。生成核心 `src/gen.js` 与附件 `src/engine.js` 一致，词库及两套阶段配置直接采用附件数据。编辑器界面、IndexedDB 存档、竞品浏览、手工编辑、实际拖动试玩和 `{books,daily}` 导出继续沿用现有实现。

## 接入边界

- 通过 `src/v2_adapter.js` 将 v2 的 grid/targets/counts/extras 转为 g/t/n/e；计数使用原游戏的 base36 编码。
- 页面内嵌新核心、词库、配置和适配层，两个 HTML 副本一致；无需构建和运行时下载生成器。
- 批量参数改为两套主线、尝试次数、冷却窗口、额外词惩罚、次数上限及种子。
- 词库浏览展示完整 9,455 条及审核原因。有效玩法词集只使用 v2 允许的 candidate / extra，待审核词不参与候选、建议或额外词扫描。
- 原有用户缩写禁表作为附加排除规则保留。默认旧名单不再承担 v2 词库管理。
- 没有将权限或“基础”标签伪装成词频。新关卡 lv 留空，旧关卡原有 lv/ty 和分册数据仍保留；无等级的新分册 mix 使用现有兼容默认值，不代表实测。
- 没有自动把已有浏览器关序迁移或删除。新词库下不符合权限的旧必答显示警告。
- 补上单格改字母前的撤回快照，避免撤回误恢复到生成前的关序。
- 全部失败或尚无成功关卡时中止，不替换用户原关序；部分成功按用户选择的插入/替换模式处理。

## 当前环境实测

两套固定种子均使用 `QA-v2-2026`，每关尝试 60 次，额外词惩罚 0.9。结果文件写到 `/tmp/current-v2-list*.json`。

| 项目 | list0 | list5 |
|---|---:|---:|
| 请求 / 成功 | 300 / 300 | 300 / 300 |
| 失败 | 0 | 0 |
| 必答词次 | 2,871 | 2,725 |
| 平均必答 | 9.57 | 9.0833 |
| 平均额外词 | 5.1267 | 4.7233 |
| Python 独立审计失败关数 | 0 | 0 |

独立审计无 JS 路径数量上限，检查所有必答路径用格是否一致、权限、全盘覆盖、逐格次数和额外词完整性。list0 审计引擎格式，list5 审计适配后的游戏格式。

补充验证：两套主线 1001–1005 共 10 关，全部成功；独立审计 95 个必答词次，失败 0。浏览器两套主线各 10 关的游戏导出也通过独立审计，分别检查 41 / 47 个必答词次。

Python 回归共 6 项通过：正样本、次数损坏、遗漏额外词、DOS/GOOS/HOTS 权限、不同用格路径、HTML/内嵌资源同步。内嵌 JS 语法检查通过。

浏览器验证入口为 `tests/browser_v2.cjs`，检查两个主线与 Node 相同参数输出一致、前 3 关实际拖动通关、单格编辑撤回、游戏 JSON 导入导出、存档重开、失败保留关序、历史分册/每日关及等级元数据保留、独立 HTML 副本运行、无 pageerror。

云端 Chromium 管理策略禁止 file:// 导航（ERR_BLOCKED_BY_ADMINISTRATOR），该项不宣称已直接验证；测试通过本地 HTTP 验证独立 HTML 副本，不修改浏览器管理策略。

## 保留的 v2 局限

候选词未逐词完成熟悉度、缩写、专名或专业词审核。近期重复是软惩罚，额外词数量和布局是评分目标。扫描器保留原 v2 的路径/节点上限；独立 Python 审计用于发现抽样输出中的漏检。v2 不生成幕布；原编辑器仍可手工编辑幕布，不能把无幕布生成器的证明直接用于幕布关卡。

历史 320 关样本、旧报告及旧路径浏览器脚本仍保留作为历史资料，不代表当前词库下通过。
