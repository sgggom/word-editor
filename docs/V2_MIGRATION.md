# 游戏词库配置迁移记录

2026-10-19，版本 2026.10.19.3：关卡台切换到七游戏词库与独立词池配置。此前 Word Tiles v2 引擎接入说明和旧词库审核原稿归档在 `archive/legacy-vocabulary-2026-10-19/`。

## 数据与默认值

迁移已校准分享页的 7 款游戏、25 份配置或资源版本、32,268 个词条，完整保留四类来源身份和逐关引用。全部集合运算数据内嵌，出处 gzip 分包按需加载；默认 Word Tiles、Zen Word、Words of Wonders、Wordscapes 四款游戏全部版本，两池可独立选择交集／并集。初始两池取并集，编译为 10,748 必答候选与 11,720 仅额外；两池取交集则为 1,627 与 579。

旧词库的生成权限、词形隔离、基础标签和审核分数退出运行。生成引擎保留棋盘结构和路径安全目标，使用统一编译后的新词表。两字母额外词在词表、建议、检查和试玩中一致支持。

## 文件与存档兼容

词库配置存入既有 IndexedDB `kv` 的 `libraries` 键。当前关序和历史文件结构继续沿用，编辑器文件添加 `librarySnapshots`，每关添加 `librarySnapshotId`。快照固定配方、版本、数据指纹、生效词表和禁表，修改或删除配方不会重写已有关卡。缺少快照的历史关卡绑定初始四游戏配置，保留内容；有引用但缺少快照或内容校验失败的文件阻止导入。

游戏导出九字段与 `{books, daily}` 格式继续使用，不携带编辑器词库信息；如需继续编辑并保持自定义词库，应保存关卡台文件。原释义和 WT／Zen 竞品关表继续提供查阅。

## 构建约定

`tools/sync_editor.py` 调用共享 JavaScript 集合编译器生成默认词表，再同步脚本、数据与两个 HTML。旧审核程序不进入当前构建或测试发现路径。新增回归覆盖集合语义、快照、来源和生成，原路径、试玩、导入导出回归继续运行。具体命令见根目录 README。

四游戏默认升级使用独立预设版本标记，只在旧配置首次载入时选中一次，保留所有已存配方和关卡快照。之后的默认值与交并集选择继续由用户保存决定。
